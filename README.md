# inventario-mexicat
Repositorio para el inventario de mexicat.cl

# Instalación
Ejecuta el script siguiente:
```bash
scripts/init
```

# Desarrollo
Para iniciar el entorno de desarrollo, ejecuta:
```bash
sail up -d
```

Para ejecutar el servidor de front usa:
```bash
sail pnpm run dev
```
